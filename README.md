# 统一交付平台

基于 GitLab CI 发布流程的多项目统一交付工作台。首版聚焦发布编排体验，覆盖上线申请、项目选择、业务线 tag 前缀、依赖顺序、统一构建、单项目部署和用户权限展示。

## 当前能力

- 统一发布入口：选择需要上线的项目，并为每个项目指定分支、tag 或 commit。
- 业务线 tag 配置：不同平台可维护独立生产 tag 前缀，例如 `aaprd`、`bbprd`。
- 依赖排序：选中的项目会按照预设 `order` 自动排序，并展示缺失依赖提示。
- 统一构建与部署：发布经理或管理员可统一打 tag、触发构建和按顺序部署。
- 单项目操作：每个已选项目支持单独构建、部署和重发，适合失败重试或补发。
- 简单权限模型：开发、发布经理、管理员三类角色对应不同操作能力。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

## 后续接入建议

- 将项目、业务线、用户与依赖关系持久化到数据库。
- 接入 GitLab API：创建 tag、触发 pipeline、读取 job 状态与日志。
- 将“提交上线流程”改为真实审批流，并记录操作审计。
- 按环境扩展前缀模板，例如 `sit`、`uat`、`prd`。
